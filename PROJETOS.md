# Catálogo de projetos

Esta página organiza os projetos com identidade própria que foram selecionados para a vitrine profissional. Ela diferencia produtos com evidências de build de protótipos ainda em QA e experimentos cujo resultado final não foi validado.

## Aplicações e interfaces

| Projeto | Objetivo | Estado |
| --- | --- | --- |
| [Study Hub Browser](case-studies/study-hub.md) | Reunir navegação e ferramentas de estudo numa aplicação desktop | Produto funcional segundo o autor; build de interface passou; empacotamento limpo e auditoria final de segurança pendentes. |
| [NORTE — landing pages](case-studies/norte.md) | Explorar variantes de páginas para apresentar um serviço educacional | Oito builds Vite passaram; QA visual/E2E e responsividade pendentes. |
| [Kambio](case-studies/kambio.md) | Plataforma com app móvel e backend de comunidade em tempo real | Bloqueios de dependências/workspace mobile e testes integrados pendentes. |
| [Raspadinha (equipe)](case-studies/raspadinha.md) | Manutenção e customização coletiva de uma aplicação web | Lint PHP e build frontend passaram; licença upstream e QA integrado pendentes. |

## Critério de publicação

Nem todo protótipo local precisa se tornar um destaque público. Duplicatas, pastas de testes, scaffolds sem identidade própria e ferramentas sem demonstração independente continuam fora da vitrine até existir uma contribuição clara e um nível mínimo de QA.

Código-fonte, credenciais, bancos de dados, saves, dados pessoais, mídia bruta e ativos sem autorização confirmada permanecem fora deste repositório público.
