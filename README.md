**Desenvolvedor Full-stack · React · TypeScript · JavaScript · Go · Python**  
Brasil · interesse em oportunidades remotas

Construo produtos de software orientados ao uso real: interfaces, aplicações desktop, APIs e ferramentas de produtividade. Gosto de acompanhar o produto do desenho dos fluxos à implementação e validação técnica, com atenção a UX, manutenção e segurança.

## 01 · Study Hub Browser

**Aplicação desktop para estudo e produtividade**

Um ambiente de trabalho que reúne navegação, anotações, tarefas, cronograma, flashcards, mapas mentais e leitura de documentos.

## Critério de transparência

- As capturas usam interfaces locais e, quando aplicável, dados fictícios.
- Um build ou uma checagem de sintaxe não equivale à aprovação de todos os fluxos nem à prontidão para produção.
- Não publico métricas comerciais, acurácia de ML ou resultados não medidos.
- Código-fonte, segredos, bancos de dados e arquivos operacionais permanecem privados.
